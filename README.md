# marketgame.click — Market Game: Capture the Market

Веб-версия деловой игры для американского рынка. Работа идёт по
[CONCEPT.md](CONCEPT.md): там все решения и порядок работ.

Сейчас в репозитории лежит v4.9 — русская версия для Telegram — как
отправная точка. Её инструкция по развёртыванию:
[docs/v4.9-ru/README-v4.9.md](docs/v4.9-ru/README-v4.9.md).

Файла `08_training_credits.sql` из комплекта v4.9 здесь нет: в нём
реальные ники игроков, а репозиторий публичный.

```
sql/            запросы к базе, запускать по порядку
functions/game/ код Edge Function: API и экономический движок
web/            клиент
tests/          проверки
docs/v4.9-ru/   материалы русской версии — исходник для перевода
```

## Проверки

Нужен Node.js 20+.

```
npm install
npm test               # эталон экономики, переход на доллары, полнота сброса
npm run report:teams   # сколько команд переживает первый месяц
```

GitHub Actions запускает эти проверки при каждом изменении.
